Taste of MiddleEast Ordering Website

Project Goal

To create a simple and realistic ordering website concept for a restaurant where customers can choose items, review their basket, and send the full order through WhatsApp.

Main Problem Solved

Many small restaurants may not need a full online payment system at the start. This project explores a simple front-end ordering flow that helps customers prepare their order and send it directly to the restaurant via WhatsApp, avoiding complex payment integrations.

Key Features

  • Menu item cards
  • Add to basket feature
  • Quantity updates
  • Customer details form
  • WhatsApp message generation
  • Call to Order button
  • No fake online payment
  • Clear customer journey

Tools Used

HTML, CSS, JavaScript

What I Learned

I learned how to think about real customer needs, plan a practical ordering flow, and use JavaScript to make a website more interactive and useful for users.
